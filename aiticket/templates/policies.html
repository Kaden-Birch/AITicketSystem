Maintenance suppresses new incidents and pauses delivery while preserving observations. A machine window includes its configured descendants. Global windows cover every machine.

Persistent incident notifications

Enabled intervals must be at least 60 seconds. Reminders use current evidence, coalesce missed intervals, and respect Discord severity filters. Escalation changes severity only; it grants no action permission or AI allowance.

Machine and group notification overrides

Each machine belongs to at most one notification group. Precedence: machine override, then group override, then global settings. An override supplies all fields; removing it restores inheritance. Groups do not alter machine identity or maintenance dependencies.
