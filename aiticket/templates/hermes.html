API gateway settings (unused in Codex mode)

Only the application holds the provider credential. Hermes receives a credential scoped to one execution. The gateway allows text-only requests, fixes the model and output cap, and rejects tool schemas.

The input reservation uses UTF-8 bytes of the complete text-message JSON plus this overhead. This conservative bound requires a byte-based tokenizer and a verified bound on hidden provider framing. Configure a triage allowance large enough for this reservation, not just expected actual usage.

If any part is unverified, leave this unchecked. Every bound violation disables provider admission. Costs are estimates based on configured prices; use conservative prices including provider charges. Zero budgets prohibit dispatch.
