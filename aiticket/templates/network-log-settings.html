Connect UniFi
  1. On the AITicketSystem server, set AITICKET_SYSLOG_BIND_ADDRESS in /opt/aiticket/.env to its LAN IP, then run sudo docker compose up -d --build.
  2. Add the exact sender IP below. Link its UniFi connection to identify switches and access points. Sender IPs are an allowlist, not authentication.
  3. In UniFi Network, open Integration → System Logging / SIEM, select SIEM Server and the event categories you want, then enter the AITicketSystem server’s LAN IP and port 5514.
  4. Trigger a connection event and check the source’s last received time below. Allow port 5514 (UDP/TCP) from your UniFi sender through the server firewall.

The port is bound to loopback until you set the LAN address. Use the real sending console/device IP, which may differ from the API URL or reverse proxy. No API key is needed for log forwarding.
